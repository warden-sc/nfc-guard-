NFC Guard 개인정보처리방침

시행일: [YYYY-MM-DD] · 운영: [운영 주체(개인/법인명)]

NFC Guard(이하 "앱")는 사용자가 의도하지 않은 NFC 태그를 감지해 알려주는 Android 앱입니다. [운영 주체]는 「개인정보 보호법」 등 관련 법령을 지키며, 앱이 어떤 정보를 어디에 저장하고 무엇을 서버로 보내는지 아래와 같이 알려드립니다.

1. 기기 안에만 저장되는 정보 (서버로 보내지 않음)

감지 기록감지 시각, 판정 이유와 점수, 사용자의 응답("내가 태그함/안 함"). 최근 30건까지 보관합니다.
위치 기록 (선택)사용자가 "감지 기록에 위치 남기기"를 켠 경우에만, NFC 태그가 감지된 순간 한 번 측정한 위치·정확도 반경·측정 시각. 운영자 서버로 전송하지 않으며 이동 경로를 계속 추적하지 않습니다.
내 태그 동작 정보태그 동작 등록(온보딩)으로 계산한 개인 기준값.
움직임 센서 값감지 판정을 위해 최근 2.5초의 가속도·자이로 값을 메모리에 계속 덮어쓰며 유지합니다.

앱 삭제 또는 앱의 "내 데이터 삭제"로 지워집니다.

2. 서버로 보내는 정보 (데이터 제공에 동의한 경우만)

앱을 처음 실행할 때 묻고, 앱의 개인정보 설정에서 언제든 끌 수 있습니다. 동의하지 않아도 감지·알림·기기 내 기록은 그대로 동작합니다.

처리 목적의도한 태그와 의도하지 않은 접촉을 구분하는 판정 규칙·AI 모델의 개선
항목 · 서버가 발급한 익명 기기 ID(이름·전화번호·광고 ID와 연결하지 않음)
· 감지 직전 약 2.5초의 움직임 센서 값(가속도·자이로)
· 근접 센서 가려짐 여부, 주변 밝기, 화면 켜짐 여부
· 판정 점수·이유, 앱의 판정 모델 버전, 감지 시각
· 사용자의 응답("내가 태그함/안 함")과 태그 동작 등록 시의 센서 값
보내지 않는 정보위치, 이름, 연락처, 결제·카드 정보, NFC 통신 내용
자동 생성 정보서버 접속 시 IP 주소·접속 시각이 서버 로그에 남을 수 있습니다(보안·장애 대응 목적, [로그 보관 기간]).
기기 무결성 확인가짜 기기 대량 등록을 막기 위해 최초 등록 시 Google Play Integrity API로 앱·기기의 정상 여부를 확인할 수 있습니다. 이 과정의 정보 처리는 Google 개인정보처리방침을 따릅니다.

3. 보유 기간과 파기

  • 서버에 받은 감지 데이터는 받은 날부터 365일이 지나면 매일 자동 삭제합니다.
  • 앱의 "내 데이터 삭제" 또는 동의 철회 시 "서버 데이터 삭제"를 선택하면 해당 기기의 감지 데이터·응답·등록 정보를 즉시 삭제합니다.
  • 전자적 파일은 복구할 수 없는 방법으로 삭제합니다.

4. 제3자 제공과 처리 위탁

개인정보를 제3자에게 제공하지 않습니다. 서비스 운영을 위해 아래와 같이 처리를 위탁합니다.

[클라우드 업체명]서버·데이터베이스 운영 (보관 위치: [국가/리전])

국외 리전을 사용하는 경우 이전되는 국가, 시기, 방법, 보유 기간을 여기에 추가로 적어야 합니다.

5. 사용자의 권리

  • 데이터 제공 동의를 언제든 철회할 수 있습니다(앱 > 개인정보 > 데이터 제공 끄기).
  • 서버에 보낸 내 데이터를 앱에서 직접 삭제할 수 있습니다(앱 > 개인정보 > 내 데이터 삭제).
  • 열람·정정·처리정지 요청은 아래 문의처로 연락해 주세요. 익명 기기 ID로 관리하므로 앱의 기기 ID 확인이 필요할 수 있습니다.

6. 안전성 확보 조치

  • 전송 구간 암호화(HTTPS), 기기 인증 키는 서버에 해시로만 저장
  • 학습 데이터 추출은 관리자 키로만 가능, 접근 권한 최소화
  • 위치 정보는 서버로 수집하지 않음
