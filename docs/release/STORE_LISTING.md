# Google Play 스토어 등록 문구 (초안)

[출시 체크리스트](../RELEASE_CHECKLIST.md)로 돌아가기.

**작성 원칙** ([확정 범위 6절](../PROJECT_SCOPE.md#6-코드설명화면을-같이-관리하는-기준)과 Play 기만 행위 정책)
- 구현·검증한 기능만 씁니다. NFC 동작 제한(차단)은 구현·실기기 검증 전까지 쓰지 않습니다.
- "스키밍을 막는다", "100% 감지" 같은 보장 표현을 쓰지 않습니다. 감지 범위는 기기에 따라 다르다고 밝힙니다.
- 위험도 점수를 "공격 확률"로 표현하지 않습니다.

## 앱 이름 (최대 30자)
```
NFC Guard - 의도하지 않은 태그 알림
```

## 간단한 설명 (최대 80자)
```
폰을 꺼내지 않았는데 NFC가 태그되면 알림과 진동으로 바로 알려드려요.
```

## 자세한 설명 (최대 4000자)
```
가방이나 주머니 속에 있는데, 내가 폰을 꺼내 대지 않았는데도 NFC가 태그된다면?
NFC Guard는 태그 직전의 기기 움직임과 주변 상태를 보고, 사용자가 의도하지 않은 것으로 보이는 NFC 태그를 감지해 알려드려요.

■ 이렇게 동작해요
· 태그 직전 2.5초 동안 폰이 꺼내지고 리더기로 움직였는지 확인해요
· 근접 센서와 밝기로 가방·주머니 안에 있었는지도 함께 봐요
· 의심되면 알림과 전용 진동 패턴으로 바로 알려요 (화면을 보지 않아도 알 수 있어요)
· "내가 태그함 / 내가 안 함"으로 응답하면 기록에 남고, 판정 개선에 쓰여요

■ 내 태그 습관 등록
평소처럼 몇 번 태그해서 내 동작을 등록하면 정상 사용을 의심으로 잘못 알리는 일이 줄어요.

■ 감지 기록
언제 어떤 판정이 있었는지 최근 기록을 확인할 수 있어요.
원하면 감지된 순간의 위치도 함께 남길 수 있어요. 위치는 내 폰에만 저장되고 서버로 보내지 않아요.

■ 개인정보
· 데이터 제공은 선택이에요. 동의하지 않아도 모든 감지 기능이 동작해요
· 동의하면 태그 직전 움직임 센서 값과 응답만 익명 기기 ID로 보내요. 위치·연락처·결제 정보는 보내지 않아요
· 앱에서 언제든 동의를 철회하고 서버 데이터를 삭제할 수 있어요

■ 꼭 알아두세요
· NFC Guard는 결제를 막거나 취소하지 않아요. 의심 알림을 받으면 카드사·교통카드 앱에서 거래 내역을 확인하고 필요하면 카드사에 신고하세요
· 감지할 수 있는 NFC 동작의 범위는 기기와 Android 버전에 따라 달라요. 앱 첫 화면에서 내 기기의 감지 수준을 확인할 수 있어요
· 판정은 움직임 패턴 기반 추정이라 오탐·미탐이 있을 수 있어요
· 감시를 위해 보호 중 알림이 상단에 표시되고, 배터리를 일부 사용해요
```
